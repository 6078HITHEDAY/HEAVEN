The MIT License in `LICENSE` applies to source code and project scripts only.

Unless explicitly stated otherwise, the following materials are not covered by
the MIT License and remain all rights reserved by their respective owners:

- Music and sound effects
- Images, icons, textures, logos, and UI graphics
- Fonts and font files
- Charts and chart data

- Boss event data, story content, lyrics, dialogue, and scenario text
- Exported builds and packaged game content

Do not reuse, redistribute, remix, or include these materials in another
project unless you have separate permission or a separate license grants that
right.

## Project-Owned Assets

Assets created specifically for HEAVEN may be distributed with this repository
for development and review purposes. They are not automatically licensed for
reuse outside this project.

If an asset should be released under a separate open license in the future,
document it here with:

- Asset path
- Author or copyright holder
- License name
- License URL or license text
- Any required attribution

## Third-Party Assets

Third-party assets must be documented in `THIRD_PARTY.md` before release.

If the source or license of an asset is unknown, treat it as not redistributable
until its license is confirmed.
